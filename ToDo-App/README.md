# 📝 Todo List — React

A simple and clean Todo List application built with **React** to practice core React concepts such as state management, controlled inputs, event handling, conditional rendering, and immutable array updates.

## ✨ Features

- ➕ Add new tasks
- 🚫 Prevent empty tasks
- 🔁 Prevent duplicate tasks
- ✏️ Edit tasks inline
- 💾 Save edited tasks
- 🗑️ Delete tasks
- 📋 Display all tasks
- 💬 Empty-state message when there are no tasks
- 🎨 Glassmorphism-inspired UI

## 🛠️ Tech Stack

- **React**
- **JavaScript**
- **CSS**
- **Vite**

## 🧠 React Concepts Practiced

This project focuses on practical React fundamentals:

- `useState`
- Controlled inputs
- Form submission handling
- Event handling
- Conditional rendering
- Rendering lists with `.map()`
- Removing items with `.filter()`
- Immutable state updates
- Managing edit state
- Dynamic UI based on state

## 🚀 Getting Started

### Clone the repository

git clone <your-repository-url>

### Navigate to the project

cd todo-app

### Install dependencies

npm install

### Start the development server

npm start

The application will be available at the local development URL provided by Vite.
