# Stopwatch — React

A simple and elegant stopwatch application built with React.  
This project focuses on practicing React state management, effects, event handling, and JavaScript time calculations.

## ✨ Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the stopwatch
- ⏱️ Displays time in `HH:MM:SS` format
- 🎨 Clean and minimal UI
- 📱 Responsive layout

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Vite

## 🧠 React Concepts Practiced

This project was built to strengthen the following concepts:

- `useState`
- `useEffect`
- `setInterval`
- `clearInterval`
- Event handling
- Conditional rendering
- State-driven UI updates
- Component lifecycle and cleanup

## ⏱️ Time Formatting

The stopwatch internally stores elapsed time in seconds and converts it into:

HH:MM:SS
